# Celest Teng — portfolio

Static personal portfolio for GitHub Pages. No build step or dependencies.

## Publish

Use the repository `kaps-c.github.io`. Put index.html, Celest-Teng-Resume.pdf and .nojekyll in the repository root. In Settings → Pages, select deployment from the main branch and root folder.

## Edit

Update index.html for content and styling. Replace Celest-Teng-Resume.pdf to update the résumé. Theme preference is stored locally in the browser.

Content is based on the current résumé. No project-specific repository links or screenshots have been assumed.
